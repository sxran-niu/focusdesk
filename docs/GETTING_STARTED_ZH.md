# 第一次使用 FocusDesk

首页就是当天的时间安排。长期进度在左侧的“目标与回顾 → 长期进度”。

## 先体验示例

在项目目录运行：

```sh
uv run -m focusdesk --demo serve
```

浏览器打开 `http://127.0.0.1:8765`。页面顶部会注明“示例空间”。
这里的课程、120 学分目标、任务和日期都是演示数据，可以放心尝试。

1. 在首页查看学习、生活、休息的时间分配。
2. 新建任务，填写预计用时，再点“安排时间”，设置具体开始时间。
3. 试着安排到已占用的时段，程序会提示冲突。
4. 完成任务时勾选，填写实际用时，再确认。
5. 打开“长期进度”：完成任务并不会增加学分。
6. 给 IIP 示例课程“记录结果”，明确选择“已通过，成果数量已确认”。
7. 此时已确认学分才会增加；再次保存同一结果不会重复累计。

## 建立你自己的空间

在运行服务的终端按 Ctrl+C 停止，再运行：

```sh
uv run -m focusdesk serve
```

同一地址会打开独立的个人数据库，第一次是空的。

建议先在“长期进度”里建立一个目标：

1. **目标**：名称、完成日期、数量和单位，例如自己的毕业学分要求。
2. **阶段**：各学期的起止日期与计划学分。
3. **课程 / 成果**：各门课及其通过后可确认的学分。
4. **其他条件**：必修要求、论文、答辩等，按自己的培养方案填写。

然后回到首页，创建具体任务。创建任务时可以关联课程，这样就能沿着
“任务 → 课程 → 学期 → 长期目标”找到它的意义。买菜、休息等可以不关联目标。

## 日常安排

- 左右箭头切换日期，也可以直接选择日期。
- 点击“可安排 09:00–18:00”调整当日时间范围。
- “安排时间”手动添加一个任务，“填入空闲时段”按期限和优先级填充。
- 休息和固定事务也可作为任务安排，避免把整天都算成可学习时间。
- 一个任务对应一个时间段。需要几天完成的大任务，拆成几个具体步骤。
- “移出日程”只移除安排，任务仍在；任务清单里的“删除”会同时删除安排。
- 已排入别的日期的任务不会再次被自动安排。先切到原日期移出，再重新安排。

## 阶段复盘

出分后手动确认课程结果和日期。暂未出分继续保留“待确认”。
阶段目标可以修改，原始计划和每次数量变化会保留。

工作台展示的是你设定的规则，不会替学校判断毕业资格。论文等完成条件需要
单独确认。学分数不会根据做题数量、学习时长或完成任务数量推测。

每周回顾可以保存文字报告、CSV 日程和 SVG 图表。实际时间按完成当天统计，
计划时间按原日程日期统计；跨周延迟完成时，两者可能不同。

## 代码从哪里看

先读 `models.py` 理解一条任务有哪些字段，再读 `planner.py` 理解如何找空闲
时间。`service.py` 把规则连接起来，`database.py` 负责保存数据。
`cli.py` 和 `web.py` 都调用同一个核心，因此你可以先用命令行理解行为。

可以修改一条规则、运行测试、解释预期变化，逐步熟悉代码；不要只背目录结构。
